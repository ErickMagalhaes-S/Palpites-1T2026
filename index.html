🛡️ Como funciona a segurança

O site é estático: não há conta, banco de dados, API ou envio do palpite para um servidor. O segredo é criado pelo navegador com crypto.getRandomValues() e o compromisso usa SHA-256.

O recibo publicado no grupo é a referência de prazo. O horário mostrado pelo próprio site vem do aparelho e pode ser manipulado; por isso, para decidir se alguém registrou até 23:59, vale o horário da mensagem no WhatsApp ou no canal escolhido pelo grupo.

Importante: o bloqueio por horário desta página é uma conveniência de interface, não uma autoridade de tempo. Uma pessoa tecnicamente habilidosa pode alterar seu relógio ou o código local, mas não consegue mudar retroativamente o hash que já publicou no grupo.
